# Meta Ads website-form setup

Use this public landing-page URL as the destination for a Meta (Facebook or Instagram) campaign:

```text
https://realestate-crm.realestate-crm.workers.dev/enquire.html?campaign=meta-ad
```

In Meta Ads Manager, create an ad that sends people to a **Website** destination, then paste that URL. Do not use an Instant Form for this flow; the visitor fills in this branded form on the website instead.

Before publishing a campaign, add each available project in the CRM’s **Properties** screen. Visitors can choose a project on the landing page. The chosen property’s official project, type and location are recorded with the lead, then normal automatic allocation assigns it to the least-loaded eligible employee.

Each successful website enquiry appears in **All leads** with source **Meta Ads**. The page has a hidden bot field and duplicate contact/project protection for rapid resubmits.
